Has reducing US imprisonment rates been accompanied by rising crime, undermining the case for continued decarceration?

CC5: Accessing Data via API

This chart uses the US Energy Information Administration's Open Data API (base URL: api.eia.gov/v2). The specific route is electricity/electric-power-operational-data/data, which requires an API key, a frequency (annual), a data field (here, generation), and facet filters to narrow the request — fueltypeid=SUN for solar and sectorid=98 to combine all sectors into one national total. The API returns JSON with the records nested inside response.data, where each row is a ready-to-chart record with a period (year) and a generation value in thousand megawatthours — no manual cleaning required.
