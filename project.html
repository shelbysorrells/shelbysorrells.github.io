The Great Scrubbing

How DEI language disappeared from corporate America

Photo via Magnific (Premium license)

DEI
noun — "diversity, equity, and inclusion"

A conceptual framework that promotes the fair treatment and full participation of all people, particularly in workplaces, including groups that have historically faced underrepresentation or discrimination based on background, identity, or disability.

Source: Dictionary.com.

In 2025, companies across the US quietly began removing references to diversity, equity, and inclusion from their public communications — but how much of that retreat actually reached the one place companies can't easily spin: their legally mandated disclosures to investors? This project asks a specific, countable question: did the exact language companies use in SEC filings measurably change after the 2024 US election and the Trump administration's subsequent anti-DEI executive orders, and if so, how fast and how far?

Using the SEC's EDGAR full-text search system — which indexes the complete text of every public filing since 2001 — I track how often specific terms ("diversity, equity, and inclusion," "ESG," "climate risk") appear in annual 10-K filings, before and after this political shift.

This matters because SEC filings are the one corporate communication channel where companies face real legal exposure for misstatement, making any detectable shift in language a meaningful signal of how deeply political pressure has reached into formal corporate governance, not just public messaging.

The Data

This project draws entirely on live, publicly accessible government and open-source data — no proprietary datasets or paid APIs were used.

The core source is the SEC's EDGAR full-text search system (efts.sec.gov), which indexes the complete text of every public company filing since 2001. I queried this system directly for specific phrases ("diversity, equity, and inclusion," "DEI," "ESG," "climate risk") across different filing types (10-K annual reports and DEF 14A proxy statements), date ranges, and company- or state-level filters, using the API's locationCodes, ciks, and date-range parameters to isolate the data each chart needed.

Because this API blocks direct requests from a browser (a security measure called CORS), data for every chart on this page was collected using Python scripts run in Google Colab, which queried the API directly, saved the results as small static files, and uploaded those files to this site's GitHub repository. Every chart reads from one of these static files rather than querying SEC's servers live each time a visitor loads the page — a deliberate tradeoff that keeps the page fast and reliable, at the cost of the data not auto-updating after the date it was collected.

Two supporting public datasets round out the picture: a full list of S&P 500 companies, their SEC filer identifiers (CIKs), and their GICS sector classifications, pulled from a public, open-license dataset maintained on GitHub (datasets/s-and-p-500-companies); and SEC's bulk company-to-exchange mapping file, used to identify which stock exchange each company is listed on.

Across the full S&P 500, roughly half of companies' 10-Ks mentioned "diversity, equity, and inclusion" or "DEI" every year from 2022 through 2024. By 2026, fewer than 1 in 10 still did.

Even Target — the one company that still shows up as "mentioning" DEI in 2025 and 2026 — isn't describing ongoing initiatives anymore. The phrase now appears in a different context: explaining the shareholder lawsuits and consumer boycotts that followed Target's own rollback.

Tools

Data collection was done in Python, run in Google Colab notebooks, since SEC's EDGAR API blocks direct requests from a browser (a restriction called CORS) — Colab's Python environment isn't subject to that restriction. Each script used the requests library to query the API directly, with a short retry loop (up to three attempts per request) to handle the occasional server timeout, and saved results as static JSON files for the site to read from later. For the two larger company datasets, scripts also wrote periodic checkpoint files, so a dropped connection partway through a long run (the full S&P 500 pull took roughly 45 minutes) wouldn't mean losing everything already collected.

All charts were built in Vega-Lite, a JSON-based charting grammar, and embedded directly into this page with vega-embed. Several charts use Vega-Lite's interactive features beyond a static image: the state map and the company lookup tool both use dropdown parameters that let a reader switch what the chart displays without reloading the page, and the multi-term comparison chart uses hover-based highlighting to isolate one line at a time.

A few real challenges came up along the way. SEC's own aggregation features (for breaking results down by state or industry) cap out at the top 30 categories, so state-level data was instead collected by querying each state individually. Company-level full-text search has a real blind spot: a company using different wording than the exact phrases searched for will show up as "no mentions" even if it has active DEI-related language elsewhere — several companies tested throughout this project (Microsoft, Intel, and others) fell into this category and were excluded from charts where that would otherwise mislead. And GitHub Pages, which hosts this site, caches published pages for a period after each update, which occasionally made a genuinely successful upload appear not to have taken effect until the cache cleared.
